# Game Archive｜綜合遊戲圖鑑

Game Archive 是一個以 Steam 深色介面為設計靈感的遊戲介紹網站，目的是讓使用者能夠快速探索不同類型的遊戲，了解遊戲的基本資訊、核心玩法與特色。

本專案使用 HTML、CSS、JavaScript 開發，並以 JSON 統一管理遊戲資料，讓網站能夠持續新增遊戲內容。

**線上網站：** https://kevin54712-arch.github.io/game-archive/

## 主要功能

- **遊戲總覽：** 透過卡片呈現遊戲封面、名稱、類型及簡介。
- **即時搜尋：** 使用者可以輸入名稱快速尋找遊戲。
- **類型篩選：** 依照遊戲類型篩選感興趣的作品。
- **詳細介紹：** 每款遊戲都有獨立頁面，介紹遊戲背景、玩法及特色。
- **相關遊戲推薦：** 根據共同的遊戲類型自動推薦其他作品。
- **響應式設計：** 支援電腦、平板及手機瀏覽。

## 專案技術

- **HTML5：** 網頁結構與內容呈現
- **CSS3：** 深色介面與響應式排版
- **JavaScript：** 搜尋、分類及資料載入
- **JSON：** 統一管理遊戲資料
- **GitHub Pages：** 靜態網站公開部署

## AI 開發規範

本專案的核心特色是建立 `AGENTS.md`，作為 AI 的開發手冊。

文件中定義網站的設計風格、檔案結構、資料格式、命名方式、修改限制及驗收流程。

未來需要新增遊戲時，AI 必須先閱讀 `AGENTS.md`，確認開發規則並提出修改計畫，再依照既有模板建立介紹頁面，同步更新 `games.json`。

由於首頁採用資料驅動架構，新增遊戲後便能自動產生卡片，並套用原有的搜尋、分類及相關推薦功能，不需要重新設計整個網站。

## 本地預覽與驗收

本專案不需要安裝額外的前端套件。

可使用 Python 的本地 HTTP 伺服器預覽網站，並透過 `node scripts/validate.mjs` 檢查資料結構及檔案連結。
